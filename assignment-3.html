系统需求规格书（SyRS）

系统需求定义是问题域需求向方案域需求的转换：从供应商 / 研制方视角，描述系统为满足相关方需求所应具备的特性、属性、功能与性能。SyRS 只描述抽象功能与约束，不指定具体实现方案；每条需求可验证、可追溯到 StRS 条目。

SyRS

机器增强的人机混合神经系统 · 系统需求规格说明书

技术视角 / 方案域顶层
1 简介Introduction

1.1 目的把作业二确认的相关方需求转换为一组技术视角的系统需求，作为架构定义、设计实现、集成验证与安全分析的基线；本说明书回答“系统必须具备哪些功能、性能、接口与质量特性”，不规定具体器件选型与实现细节。

1.2 范围覆盖“意图采集—解码—仲裁—执行—感觉反馈—监控降级”闭环内的系统行为与属性；不含植入式器械的临床注册审批、诊断与治疗方案制定，也不替代既有康复流程。

1.3 定义与缩写术语与缩写见本章末尾缩写表；Need / Requirement、MoE / MoS 等沿用作业二定义。

1.4 参考ISO/IEC/IEEE 15288:2023；ISO/IEC/IEEE 29148:2018；郭宝柱《系统工程——基于国际标准过程的研究与实践》第 4、5 章；SAE J3187（STPA 推荐实践）；INCOSE 系统工程手册。

2 系统总体描述System overview

2.1 系统概述本系统是“被增强的人”整机内部负责意图—动作—感觉信息转换的系统层：读取使用者神经意图，解码并仲裁后驱动外部执行机构，再把机构状态编码为可辨识的感觉反馈回注；安全监控旁路全程监测并在越界时降级。

2.2 环境与边界上游对接使用者神经系统、监督者与任务环境；下游对接外骨骼 / 机械臂 / 线控装置等执行机构；与算法平台、接口设备通过明确接口交换信号、数据与状态。系统边界不包含人的生理康复过程本身，也不包含机构的机械结构设计。

2.3 运行模式离线校准模式、在线闭环模式、被动待机模式、安全降级模式、维护模式；模式之间互锁，状态切换需满足约定条件。

2.4 相关方与用户特征使用者为康复患者 / 驾驶员 / 作业人员；监督者为康复师或作业管理者；其余相关方见作业二 StRS 相关方列表 S1–S10。

2.5 总体假设与约束课程项目周期内完成概念与原型验证；无临床级植入设备；实验受试者与场地有限；定量基线待后续实验回填。

逻辑架构

LOGICAL VIEW

由支持系统逻辑运行的技术概念与原理组成：控制器（解码、仲裁、安全监控）、执行器（机构驱动、刺激发生）、传感器（神经采集、状态感知）、被控过程（使用者肢体与作业对象）与外部监督者，按命令—反馈回路组织。

功能架构

FUNCTIONAL VIEW

物理架构

PHYSICAL VIEW

HW-3STPA

基于 STPA 的安全需求与安全架构

在初始架构（图 3-2 控制框图）上做系统理论过程分析：先定义事故与危险、高层安全约束，再在控制结构中识别不安全控制动作（UCA），追溯致因场景后导出安全需求；安全需求再落到独立的安全架构中实现。方法参照 SAE J3187（STPA 推荐实践）。

分析步骤

① 定义目的与范围（损失 / 危险 / 安全目标）

② 构建分层控制结构

③ 识别不安全控制动作 UCA

④ 识别致因场景，导出安全需求与对策

安全需求进入 SyRS SYS-Q-01 与架构实现。

STEP 1事故 / 损失、危险与高层安全约束

事故与损失（Losses）

L-1 使用者身体损伤（刺激过强 / 过久、机构冲击夹挤、过度牵拉）；L-2 周边人员被机构动作伤及；L-3 误动作造成任务失败或二次伤害；L-4 神经 / 生理数据泄露或越权使用；L-5 长期佩戴造成皮肤或神经慢性损伤。

高层安全约束（Safety Goals）

系统不得在无有效意图与置信度支撑下驱动机构；运动必须在限位内；刺激强度与时长必须限幅；越界 / 断链 / 急停时必须进入安全降级；生理数据受控；反馈缺失必须提示而非静默。

STEP 2分层控制结构

控制结构即图 3-2 系统控制框图：监督者（外部控制器）— 控制器（解码 / 仲裁 / 安全监控）— 执行器（机构驱动 / 刺激发生）— 被控过程（使用者肢体 / 外骨骼 / 作业对象）— 传感器（神经采集 / 状态力觉感知），环境作为外部扰动纳入。STPA 在该结构上沿控制链路与反馈链路查找不安全控制动作。

STEP 3不安全控制动作（UCA）识别

按四类 UCA 排查：未提供应提供的控制动作；提供了不安全的控制动作；错误时机（过早 / 过晚 / 时序错位）；控制动作持续过久或停止太晚。

分层与独立

INDEPENDENCE

安全监控层独立于主控实现：看门狗、联锁判断、限位与刺激校验单独运行；安全相关动作不能只经过主控放行。

REDUNDANCY

机构限位软件 / 机械双通道；刺激限流硬件独立；急停硬链路直抵执行层，单点故障不导致危险动作。

DEGRADATION
