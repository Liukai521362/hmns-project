# 机器增强的人机混合神经系统

吉林大学・车辆工程・复杂系统工程课程小组课题的课题主页。

本仓库同时承担两件事：**课题门面**（对外说明我们研究什么、在六层体系里处于哪一层）与**过程档案**（每次作业的结论、依据和遗留问题都在这里留痕，可直接交给任课老师查阅）。

## 页面内容



| 章节   | 内容                                            |
| ---- | --------------------------------------------- |
| 总览   | 定位说明：所选系统处于第四层「系统 Systems」，并解释为什么它不是整机        |
| 六层梳理 | 任务 → 体系 SoS → 整机 → 系统 → 子系统 → 模块，逐层补全要素，可点选切换 |
| 系统解剖 | 生物神经层 / 接口层 / 机器算法与执行层三层通路，五个子系统与模块划分表        |
| 信号闭环 | 上行意图链路与下行反馈链路的闭环图，t₁…t₇ 时延预算分配点               |
| 验证指标 | 每个指标怎么测、拿什么判定，数值留待实验回填                        |
| 作业提交 | 作业清单、对应章节、提交位置与状态                             |
| 进度   | 从选题到期末汇报的时间节点                                 |

页面是单个自包含的 `index.html`：CSS、JS、图形全部内联，没有外部依赖（除字体 CDN），双击即可打开。

## 本地预览

双击 `index.html`。如需通过本地服务器打开（避免个别浏览器对 `file://` 的限制）：



```
python -m http.server 8000
```

然后访问 [http://localhost:8000](http://localhost:8000)。

## 发布到 GitHub Pages

### 方式一：网页上传（不用命令行）



1. 在 GitHub 新建仓库，例如 `hmns-project`，可见性选 Public。

2. 进入仓库 → **Add file → Upload files**，把 `index.html` 和 `README.md` 拖进去 → Commit。

3. 进入 **Settings → Pages**，`Source` 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。

4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/hmns-project/`。

### 方式二：命令行



```
cd hmns-site

git init

git add .

git commit -m "init: 课题主页"

git branch -M main

git remote add origin https://github.com/<你的用户名>/hmns-project.git

git push -u origin main
```

推上去之后同样在 **Settings → Pages** 里开启 Pages，分支 `main`、目录 `/ (root)`。

> 如果仓库名取作 
>
> `<你的用户名>.github.io`
>
> ，则页面直接发布在 
>
> `https://<你的用户名>.github.io/`
>
> ，不需要子路径。

## 把页面上的仓库按钮接上你自己的仓库

打开 `index.html`，修改 `<head>` 里这两行（约在第 10 行）：



```
\<meta name="repo-user" content="">

\<meta name="repo-name" content="">
```

填入后，「打开课题仓库」「提交新作业（Issue）」两个按钮就会跳到你自己的仓库；留空时点击会提示去配置，不会跳到错误地址。

## 作业提交流程



1. 在本页对应章节更新内容（章节号与作业编号一一对应）。

2. 提交一次 commit，commit message 写 `A-03: 闭环信号流与时延预算` 这样的格式。

3. 开一条 Issue，标题 `[A-03] 闭环信号流与时延预算`，正文按模板写三节：



```
\## 结论

\## 依据

\- 引用页面章节：

\- 参考材料：

\## 遗留问题

\-
```



1. 结论变化时更新 Issue 而不是新开一条，让一条记录能完整追溯推导过程。

## 内容约定



* 页面不放未经验证的实验数值。时延、准确率等指标以变量占位（t₁…t₇），实验完成后由小组回填并注明测量条件。

* 引用外部资料时写明来源与获取日期。

* 章节结构与课堂上「任务 — 体系 SoS— 整机 — 系统 — 子系统 — 模块」的链条保持一致，改动前先在组内对齐。
