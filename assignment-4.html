HW-4LAYERING

场景分层

场景是“在一定环境条件下，参与者为完成既定任务而发生的、具有时间顺序的活动序列”。先按抽象程度区分功能场景、逻辑场景、具体场景三类；再把系统所处任务环境拆成若干环境层，逐层描述要素，避免把场地、人体、交互对象、物理条件、数字链路与临时扰动混在同一层。

场景抽象层次

功能场景：自然语言描述任务与目标。

逻辑场景：变量与取值区间。

具体场景：给定初始条件与参数的实例。

环境分层参照自动驾驶场景分层思路，移植到人机混合神经系统任务环境。

功能场景

FUNCTIONAL SCENARIO

最高抽象层：用自然语言描述“在什么类型的环境中，谁为完成什么任务而活动”，只表达意图与目标，不含具体数值与个体参数。

逻辑场景

LOGICAL SCENARIO

中间层：把功能场景展开为一组变量及其取值区间与约束关系（如任务类型、位姿范围、人员状态、环境条件区间），描述一类可运行的场景集合。

具体场景

CONCRETE SCENARIO

最低抽象层：给定具体初始条件、参数取值与参与者状态的单个实例，可直接用于试验、验证与风险复现；作业四选取的典型场景即具体场景实例。

LAYERS任务环境六层划分

由外向内、由静态到动态逐层收敛：场地与任务 → 人体与生理 → 交互对象 → 物理环境 → 数字链路 → 临时扰动。上层要素是下层要素存在的背景。

HW-4ODC

运行设计条件（ODC）设定

设计运行条件（ODC）是系统设计时确定的、适用于功能运行的各类条件总称，参照 ISO 34503 与 DORAD 框架分为三类：设计运行范围（ODD，外部环境条件）、系统状态、人员状态。系统在 ODC 内方可进入在线闭环；任一条件即将越界时，按作业三降级层次后撤。

ODC 顶层三类

① 设计运行范围 ODD：场地、对象、人员、物理与数字外部条件。

② 系统状态：自检、模式、信号、解码、运动、刺激、反馈、故障。

③ 人员状态：使用者、监督者、周边人员。

ODC 边界可带时间属性；越界前应可被监控并触发降级。

ODDA. 设计运行范围（外部环境条件）

回答“系统可以在什么外部环境里运行”。允许条件即本课程原型的设计边界；越界条件对应待机、柔顺辅助或降级路径。

ODC 的时间属性

部分边界带时间属性，如“连续疲劳不超过约定时长”“低电量剩余时长应大于当前任务预估时长”；具体时长阈值 tba，由后续试验标定。

越界处理原则

系统持续监控 ODC 与自身状态；在即将不满足 ODC 时触发提示、柔顺辅助或降级；不满足条件时不进入在线闭环，危险状态进入被动安全或急停断开（衔接作业三 SR-01～SR-10）。

CONCRETE

典型场景 S-01 · 上肢康复训练柔顺辅助

具体场景实例 / 系统层
场景陈述Scenario statement

在受控康复训练室、台面与机构包络已标定、使用者上肢在位且系统自检通过的条件下，使用者通过上肢屈曲 / 伸展意图触发外骨骼柔顺辅助完成一组训练动作；监督者在岗观察并可随时介入；系统在软件与机械限位、刺激限幅内闭环运行，把机构位置与接触状态编码为感觉反馈回注使用者，训练结束后记录全过程供复盘。

参与角色Actors

使用者康复受试者，目标上肢佩戴采集与反馈接口，产生意图并接受柔顺辅助与感觉反馈。

监督者康复师，在岗观察信号质量、动作幅度与使用者状态，可发起监督级急停或暂停。

系统作业三五子系统：神经信号采集、意图解码、机器增强与反馈刺激、执行协同控制、供能通信与安全监控。

作业对象与环境训练教具；受控康复训练室，周边人员在包络之外。

前置条件Preconditions

ODD 满足场地、空间、周边人员、光照、温度、噪声振动、电磁、链路与供能条件均在第三章允许边界内。

系统状态满足自检通过，处于在线闭环（或柔顺辅助）模式；信号质量、解码置信度、限位与刺激限幅、反馈一致性均正常；急停硬链路可用。

人员状态满足使用者在位位姿正确、注意力集中、生理基线正常且已知情同意；监督者在岗；周边人员未侵入。

⑤ 反馈回注使用者感知机构状态并调整动作。状态感知获取位置 / 力 / 接触，编码为触觉 / 力觉提示，经限幅后回注；上下行时序对齐。反馈缺失 / 错位 → 明确告警，不静默继续（SR-06）；刺激超限 → 硬件切断（SR-04）。
⑥ 记录复盘监督者结束训练，查看过程记录。留存校准记录、指令与反馈事件、异常事件；数据脱敏分级存储，可导出复盘。断链 / 断电 → 被动安全状态，上电不自恢复，需人工确认（SR-05）。

佩戴与启动流程可在监督者协助下完成；异常可被使用者与监督者感知；记录完整可追溯；ODC 边界与降级路径在本场景下被实际触发验证。
